# Стендовый светильник ESP32 по Wi-Fi

Прошивка MicroPython использует управляемый индикатор самой платы. Он мигает один раз после добавления «Светильника ESP32» в «Контур» и четыре раза при каждом нажатии «Включить» в карточке. После сигнала индикатор возвращается в исходное состояние. Дополнительные детали для этого варианта не нужны.

## Вариант Arduino с внешним светодиодом

Для **ESP32-DevKitC V4 с модулем ESP32-WROOM-32E** подходит вывод с маркировкой `IO23`. Для другой модели проверь её распиновку и укажи свободный выход в `KONTUR_LED_GPIO`. [Распиновка ESP32-DevKitC V4](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-devkitc/user_guide.html)

```text
GPIO23 ─── [330 Ω] ─── анод (+) LED катод (−) ─── GND
                        длинная ножка  короткая ножка
```

Отсоедини USB, собери цепь на макетной плате и снова подключи USB. Используй один обычный красный светодиод и последовательный резистор 330 Ω от 0,125 Вт. Катод обычно со стороны плоской грани корпуса. Питание платы поступает по USB, а выход GPIO подаёт на цепь до 3,3 В. Схема рассчитана на один маломощный светодиод.

### Загрузка скетча Arduino

1. В Arduino IDE установи пакет плат **esp32 by Espressif Systems** версии **3.3.5** и библиотеку **ArduinoJson 7.x**. [Настройка Arduino-ESP32](https://docs.espressif.com/projects/arduino-esp32/en/latest/installing.html), [библиотека ArduinoJson](https://arduinojson.org/v7/)
2. Скопируй `secrets.example.h` в `secrets.h` рядом со скетчем. Укажи SSID в `kWifiSsid`, пароль в `kWifiPassword` и случайный токен из 32–128 символов `A-Z a-z 0-9 _ -` в `kDeviceToken`. Установи `KONTUR_LED_GPIO` в номер подключённого вывода. Значение `-1` оставляет выход и сетевую часть выключенными. Git игнорирует `secrets.h`.
3. Открой `KonturWifiLight.ino`, выбери модель платы и её COM-порт и загрузи скетч. При старте светодиод погашен.
4. Запусти локальный мост по инструкции в [README проекта](../../README.md). Компьютер и ESP32 должны быть в одной сети с доступным mDNS. В приложении найди **Светильник ESP32** среди устройств Wi-Fi и при запросе введи `kDeviceToken`.

## Встроенный индикатор с MicroPython

Прошивка в папке [`micropython`](./micropython) передаёт имя и кнопку «Включить». Локальный мост находит плату через UDP на порту `42424` в домашней сети. Добавление с верным кодом запускает один сигнал; обновление списка и чтение состояния сигналов не запускают.

1. Для классического ESP32 с 4 МБ флеш-памяти используй образ [MicroPython ESP32_GENERIC](https://micropython.org/download/ESP32_GENERIC/). Если на плате стояла другая прошивка, сохрани её перед заменой. Сотри флеш-память согласно инструкции MicroPython и запиши официальный образ по адресу `0x1000`.
2. Скопируй `kontur_config.example.py` в `kontur_config.py`. Укажи `DEVICE_TOKEN` для управления по сети, 64-символьный шестнадцатеричный `SETUP_KEY` и отдельный уникальный `SETUP_AP_PASSWORD` для временной сети `Kontur-…`. Последние шесть символов имени сети совпадают с последними шестью символами идентификатора прибора. Домашняя сеть задаётся при подключении к «Контуру» и сохраняется только после успешного подключения. Укажи вывод индикатора в `LED_GPIO`, а если он загорается при низком уровне, задай `LED_ACTIVE_LOW = True`. Например, на DOIT ESP32 DevKit V1 встроенный светодиод подключён к `GPIO2`. Индикатор питания оригинальной DevKitC V4 подключён к питанию платы. [DOIT ESP32 DevKit V1 в Arduino-ESP32](https://github.com/espressif/arduino-esp32/blob/master/variants/doitESP32devkitV1/pins_arduino.h) · [Схема Espressif DevKitC V4](https://dl.espressif.cn/dl/schematics/esp32_devkitc_v4_sch.pdf)
3. Установи [mpremote](https://docs.micropython.org/en/latest/reference/mpremote.html). Из папки `micropython` запиши файлы и перезагрузи плату (замени `COM6`, если порт другой):

   ```powershell
   py -m mpremote connect COM6 fs cp kontur_config.py :kontur_config.py
   py -m mpremote connect COM6 fs cp kontur_provision.py :kontur_provision.py
   py -m mpremote connect COM6 fs cp kontur_portal.py :kontur_portal.py
   py -m mpremote connect COM6 fs cp main.py :main.py
   py -m mpremote connect COM6 reset
   ```

4. Открой [официальную панель](https://nexus-home-assistant.onrender.com/#page=devices), выбери комнату и нажми **Добавить прибор**. Подключи телефон к `Kontur-…` с паролем настройки и открой страницу прибора из той же вкладки. После подключения к домашней сети прибор добавится в комнату, когда его увидит облачный сервер. Для отдельной локальной панели используй поиск в домашней сети и `DEVICE_TOKEN`.

## Проверка Arduino

В мониторе последовательного порта на **115200 бод** дождись строк `HTTP address:` и `Announcing …`. Включи светильник в приложении. Светодиод должен зажечься на 50%. Сравни яркость при 20% и 100%, затем выключи питание. Плата напечатает строку `Light state: …` после успешной записи. При потере Wi-Fi она погасит светодиод и сохранит выбранный уровень яркости до перезагрузки. [Arduino-ESP32 LEDC](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/ledc.html)

Для проверки манифеста открой в браузере адрес платы из монитора порта с путём `/kontur/v1/manifest`. Проверь состояние в приложении после добавления прибора и ввода токена. Пример первоначального состояния:

```json
{"power":false,"brightness":50}
```

| Метод и путь | Результат |
| --- | --- |
| `GET /kontur/v1/manifest` | Манифест версии 1 с ID платы, типом `light`, признаком `requiresToken` и возможностями |
| `GET /kontur/v1/state` | Последнее состояние в виде JSON |
| `POST /kontur/v1/command` | Принимает JSON с полями `capability` и `value`. Возвращает обновлённое состояние |

Для чтения состояния и отправки команды нужен заголовок `Authorization: Bearer <токен прибора>`. Для команды также нужен `Content-Type: application/json`. Питание принимает `true` или `false`, яркость принимает целое число от 0 до 100. При перезапуске питание сбрасывается, яркость возвращается к 50%.

Соединение моста с платой использует обычный HTTP. Токен защищает от случайных команд в доверенной тестовой сети. Для реальных приборов потребуется шифрование, аутентификация устройств и проверенная схема управления.
