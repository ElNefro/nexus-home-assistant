# Прошивки «Контура»

Для текущей панели используй [Wi‑Fi-светильник ESP32](KonturWifiLight/README.md) на Arduino или MicroPython. Панель читает название и возможности с платы и подбирает элементы управления.

## Архив: стендовый увлажнитель ESP32 по Bluetooth

Этот скетч документирует ранний стенд. В текущей панели добавление новых приборов работает по Wi‑Fi.

Скетч `KonturHumidifier/KonturHumidifier.ino` нужен для проверки обнаружения прибора, обмена командами и получения показаний по Bluetooth Low Energy. Питание увлажнителя, влажность воздуха и уровень воды моделируются в памяти платы.

## Загрузка

1. Установи пакет плат **esp32 by Espressif Systems** версии **3.3.5** в Arduino IDE. Используется BLE-библиотека из пакета. [Инструкция Espressif](https://docs.espressif.com/projects/arduino-esp32/en/latest/installing.html)
2. Подключи плату по USB, выбери в Arduino IDE её точную модель и COM-порт. Поддерживаемый чип должен иметь BLE, например ESP32, ESP32-C3 или ESP32-S3. Если адаптер CP2102 в диспетчере устройств показывает код 28, установи драйвер и переподключи плату. [Драйвер Silicon Labs](https://www.silabs.com/software-and-tools/usb-to-uart-bridge-vcp-drivers)
3. Загрузи скетч. В режиме по умолчанию плата видна как **Увлажнитель** сразу после включения.
4. Используй отдельный BLE-клиент и формат GATT ниже. В мониторе порта с частотой 115200 и включённым переводом строки можно отправить `humidity 42`, затем `water 0`. Команда `water 65` восстанавливает уровень воды.

Чтобы проверить подключение с кнопки, установи `kPairingButtonGpio` в номер свободного GPIO с поддержкой внутренней подтяжки. Сверься со схемой платы и выбери вывод без функций загрузки или питания. Замыкание кнопки на GND в течение 10 секунд открывает двухминутное окно обнаружения. Подключение сохраняется после закрытия окна. Для повторного поиска после разрыва можно удержать кнопку снова.

## Формат GATT

Сервис `933f3720-bc7f-4dd1-b631-ab694240dd81` передаётся в BLE-объявлении, имя передаётся в ответе на сканирование.

| Характеристика | Операция | Данные |
| --- | --- | --- |
| `933f3721-bc7f-4dd1-b631-ab694240dd81` | READ | UTF-8 JSON `{"v":1,"kind":"humidifier","id":"0123456789ab","telemetry":1}`. Идентификатор из 12 шестнадцатеричных цифр стабилен для платы. |
| `933f3722-bc7f-4dd1-b631-ab694240dd81` | READ, NOTIFY | Пять байтов `[1, питание, цель, влажность, уровень воды]`. Питание 0 или 1, цель 30–70%, показания 0–100%. |
| `933f3723-bc7f-4dd1-b631-ab694240dd81` | WRITE с ответом | Два байта: `[1, питание]` либо `[2, цель]`. Плата пропускает неподдерживаемые команды и значения. |

Ответ GATT подтверждает доставку записи на сервер. Считай команду выполненной после получения соответствующего значения в телеметрии. Отправляй следующую команду после подтверждения предыдущей.

Стенд работает без аутентификации, управляет только моделируемым состоянием и сбрасывает его после перезапуска. Для реального прибора потребуются подтверждение владения, защищённая связь, проверенная схема питания и датчиков и испытания на целевой плате.
